## 关于第三方订阅

如果官方付款条件没问题，我一般建议优先考虑官方渠道。

如果没有合适的海外付款条件，需要人民币付款或者中文订单查询，再去比较第三方服务。

无论选择哪一种第三方，都建议先确认：

- 买到的到底是什么套餐
- 会员开到自己的账号还是交付其他账号
- 订单有没有记录
- 付款失败怎么处理
- 售后在哪里找
- 是否要求提供密码、验证码、Cookie 或 Session

不要因为“充值”两个字，就默认必须把账号控制权交给别人。
